Chapitre 1
Vocabulaire et concepts fondamentaux
1.1 Experience aleatoire

Une experience aleatoire (ou epreuve) est une experience dont le resultat ne peut pas etre predetermine avec certitude avant sa realisation. Chaque repetition de l'experience peut donner un resultat different. Le lancer d'un de, le tirage d'une carte, ou le choix au hasard d'une personne dans un groupe sont des exemples d'experiences aleatoires.

L'ensemble de tous les resultats possibles d'une experience aleatoire est appele l'univers, note generalement par la lettre grecque Omega (grand Omega). Chaque element de Omega est un evenement elementaire ou issue de l'experience.

Exemple 1 - Lancer d'un de a six faces

L'univers est : Omega = {1, 2, 3, 4, 5, 6}

Il contient 6 evenements elementaires. Chaque face du de represente une issue possible de l'experience.

Exemple 2 - Lancer d'une piece

L'univers est : Omega = {Pile, Face}

Il contient 2 evenements elementaires. Cette experience est aussi appelee epreuve de Bernoulli.

Exemple 3 - Tirage d'une carte dans un jeu de 32

L'univers est l'ensemble des 32 cartes. Card(Omega) = 32

Chaque carte est un evenement elementaire.

1.2 Evenements

Un evenement est une partie (sous-ensemble) de l'univers Omega. On dit que l'evenement est realise lorsque le resultat de l'experience appartient a cet ensemble. Les evenements se notent generalement par des lettres majuscules : A, B, C...

Il existe plusieurs types d'evenements particuliers que l'on rencontre frequemment dans les exercices :

  • Evenement certain : l'univers Omega lui-meme. Il est toujours realise. P(Omega) = 1
  • Evenement impossible : l'ensemble vide, note par la lettre grecque omega minuscule. Il n'est jamais realise. P({}) = 0
  • Evenement elementaire : un singleton, c'est-a-dire un ensemble contenant exactement une issue
  • Evenement contraire : si A est un evenement, son contraire est le complementaire de A dans Omega, note A barre (A avec une barre au-dessus). Il contient toutes les issues qui ne sont pas dans A
A retenir

Si A est un evenement, alors : P(A barre) = 1 - P(A). Cette relation fondamentale est utilisee dans de tres nombreux exercices.

1.3 Operations sur les evenements

On peut combiner les evenements a l'aide des operations ensemblistes classiques. Ces operations sont essentielles pour modeliser des situations complexes a partir d'evenements simples.

A union B : au moins l'un des deux evenements se realise
Union (OU logique)
A inter B : les deux evenements se realisent simultanement
Intersection (ET logique)

Deux evenements A et B sont dits incompatibles (ou disjoints) si leur intersection est vide, c'est-a-dire A inter B = ensemble vide. Dans ce cas, ils ne peuvent pas se realiser en meme temps.

Si A et B sont incompatibles, on a : P(A union B) = P(A) + P(B). Cette propriete est la base du calcul des probabilites pour les evenements disjoints, et elle s'etend a un nombre fini d'evenements deux a deux incompatibles.

Attention

Ne pas confondre evenements incompatibles et evenements independants. Deux evenements incompatibles ne peuvent pas se produire simultanement, tandis que deux evenements independants sont tels que la realisation de l'un n'affecte pas la probabilite de l'autre.

Chapitre 2
Analyse combinatoire et denombrement
2.1 Factorielle d'un entier

En analyse combinatoire, la factorielle d'un entier naturel n est le produit de tous les entiers positifs inferieurs ou egaux a n. La factorielle est notee par un point d'exclamation apres le nombre, par exemple n! (prononcee "n factorielle").

n! = n x (n-1) x (n-2) x ... x 2 x 1
Factorielle de n
Par convention : 0! = 1 et 1! = 1
Cas particuliers
Exemples de factorielles

3! = 3 x 2 x 1 = 6

5! = 5 x 4 x 3 x 2 x 1 = 120

7! = 5040

10! = 3 628 800

Propriete fondamentale

n! = n x (n-1)! . Cette relation de recurrence permet de calculer toute factorielle a partir de la precedente. Elle est tres utilisee dans les simplifications d'expressions combinatoires.

2.2 Arrangements

Un arrangement de p elements parmi n (avec p inferieur ou egal a n) est une suite ordonnee de p elements choisis parmi n. L'ordre compte dans un arrangement : les arrangements (A, B) et (B, A) sont differents si A est different de B.

A(n,p) = n! / (n-p)!
Nombre d'arrangements de p elements parmi n

Cette formule compte le nombre de facons de choisir p objets parmi n, en tenant compte de l'ordre. Par exemple, le nombre de facons d'attribuer 3 prix (or, argent, bronze) a 10 athletes est A(10,3) = 720.

Exemple - Arrangements

Combien de mots de 3 lettres peut-on former avec les lettres A, B, C, D ?

Ici n = 4 et p = 3 :

A(4,3) = 4! / (4-3)! = 4! / 1! = 24

On peut former 24 mots differents (ABC, ACB, BAC, BCA, CAB, CBA, ABD, ADB, ...).

2.3 Permutations

Une permutation de n elements est un arrangement de n elements parmi n. C'est donc une reordering complete de l'ensemble. Le nombre de permutations de n elements est simplement n! (n factorielle).

P(n) = n!
Nombre de permutations de n elements
Exemple - Permutations

De combien de facons peut-on asseoir 5 personnes autour d'une table ?

P(5) = 5! = 120

S'il s'agit d'une table ronde (les rotations sont identiques), on divise par 5 : 120 / 5 = 24 facons.

2.4 Combinaisons

Une combinaison de p elements parmi n (avec p inferieur ou egal a n) est un sous-ensemble non ordonne de p elements choisis parmi n. Contrairement aux arrangements, l'ordre ne compte pas dans une combinaison : {A, B} et {B, A} representent la meme combinaison.

C(n,p) = n! / [p! x (n-p)!]
Nombre de combinaisons de p elements parmi n

Les combinaisons sont aussi notees avec la notation entre parentheses C avec n en bas et p en haut, ou avec le symbole "n parmi p" (un grand C avec n et p). Elles sont omnipresentes en probabilites car elles permettent de compter le nombre de sous-ensembles possibles.

Exemple - Combinaisons

Dans une classe de 30 eleves, on veut choisir 4 delegues. Combien de choix possibles ?

C(30,4) = 30! / (4! x 26!) = 27 405

L'ordre n'importe pas : choisir Alice puis Bob puis Clara puis David est le meme choix que choisir David puis Clara puis Bob puis Alice.

2.5 Proprietes des combinaisons
C(n,0) = C(n,n) = 1
Choisir 0 ou n elements parmi n : 1 seule possibilite
C(n,1) = C(n,n-1) = n
Choisir 1 ou n-1 elements parmi n
C(n,p) = C(n,n-p)
Symetrie : choisir p elements revient a en exclure n-p
Triangle de Pascal

C(n,p) = C(n-1,p-1) + C(n-1,p). Cette relation permet de construire le triangle de Pascal et de calculer les coefficients binomiaux recursivement.

(a + b) puissance n = Somme de k=0 a n de C(n,k) x a puissance (n-k) x b puissance k
Formule du binome de Newton
Conseil pratique

Lorsqu'on pose un exercice de denombrement, identifiez d'abord si l'ordre compte ou non. Si l'ordre compte, utilisez les arrangements. Si l'ordre ne compte pas, utilisez les combinaisons. Puis determinez s'il y a remise ou non.

Chapitre 3
Probabilites sur un univers fini
3.1 Definition d'une probabilite

Soit un univers fini Omega. Une probabilite P est une application de l'ensemble des parties de Omega (tous les evenements possibles) dans l'intervalle [0, 1] qui verifie les trois axiomes fondamentaux suivants, poses par le mathematicien Andrei Kolmogorov.

1
Axiome 1 : Normalisation

Pour tout evenement A, la probabilite est positive : 0 inferieur ou egal a P(A) inferieur ou egal a 1. La probabilite de l'evenement certain est 1 : P(Omega) = 1

2
Axiome 2 : Evenement certain

La probabilite de l'univers entier est toujours egale a 1. Cela signifie qu'un des resultats possibles se produira obligatoirement

3
Axiome 3 : Additivite

Si A et B sont deux evenements incompatibles (A inter B = ensemble vide), alors P(A union B) = P(A) + P(B). Cette propriete s'etend a tout nombre fini d'evenements deux a deux incompatibles

3.2 Probabilite sur un univers equiprobable

Dans le cas frequent ou tous les evenements elementaires ont la meme probabilite (situation d'equiprobabilite), le calcul de la probabilite d'un evenement A se simplifie considerablement. C'est la formule de Laplace, qui est la plus utilisee dans les exercices.

P(A) = Card(A) / Card(Omega) = nombre de cas favorables / nombre de cas possibles
Formule de Laplace (equiprobabilite)

Cette formule dit que la probabilite d'un evenement A est le rapport entre le nombre de resultats favorables (ceux qui realisent A) et le nombre total de resultats possibles. Elle ne s'applique que si tous les resultats sont equiprobables.

Exemple 1 - Lancer d'un de equilibre

Quelle est la probabilite d'obtenir un nombre pair ?

A = {2, 4, 6}, donc Card(A) = 3 et Card(Omega) = 6

P(A) = 3/6 = 1/2 = 0,5

La probabilite d'obtenir un nombre pair est de 50%.

Exemple 2 - Tirage dans un jeu de 32 cartes

Quelle est la probabilite de tirer un Roi ?

P(Roi) = 4/32 = 1/8

Quelle est la probabilite de tirer un coeur ou un Roi ?

P(Coeur union Roi) = P(Coeur) + P(Roi) - P(Coeur inter Roi) = 8/32 + 4/32 - 1/32 = 11/32

3.3 Proprietes fondamentales
P(A barre) = 1 - P(A)
Evenement contraire
P(ensemble vide) = 0
Evenement impossible
P(A union B) = P(A) + P(B) - P(A inter B)
Formule generale de la reunion (inclusion-exclusion)

La formule d'inclusion-exclusion est essentielle : elle permet de calculer la probabilite de la reunion de deux evenements, meme s'ils ne sont pas incompatibles. Le terme P(A inter B) corrige le comptage double des issues appartenant aux deux evenements.

Exemple d'application de l'inclusion-exclusion

Dans une classe de 40 eleves : 25 aiment le football, 18 aiment le basket, et 8 aiment les deux.

Probabilite qu'un eleve aime au moins un sport :

P(F union B) = 25/40 + 18/40 - 8/40 = 35/40 = 7/8

Probabilite qu'un eleve n'aime aucun sport : 1 - 7/8 = 1/8

3.4 Extension a trois evenements

La formule d'inclusion-exclusion s'etend a trois evenements A, B et C. Cette formule plus generale est utile dans les exercices ou trois criteres sont impliques simultanement.

P(A union B union C) = P(A) + P(B) + P(C) - P(A inter B) - P(A inter C) - P(B inter C) + P(A inter B inter C)
Inclusion-exclusion pour 3 evenements
Erreur frequente

N'oubliez pas de soustraire les intersections deux a deux ET de rajouter l'intersection des trois. Beaucoup d'eleves oublient le dernier terme et obtiennent un resultat incorrect.

Points cles du chapitre

Toujours verifier que la somme des probabilites de tous les evenements elementaires vaut 1. Toujours verifier que chaque probabilite est entre 0 et 1. Utiliser l'equiprobabilite uniquement quand tous les evenements elementaires ont la meme chance de se realiser.

Chapitre 4
Probabilites conditionnelles et independance
4.1 Probabilite conditionnelle

Soit un univers Omega muni d'une probabilite P, et soit B un evenement tel que P(B) soit strictement positif. La probabilite conditionnelle de A sachant B, notee P(A|B) ou P_B(A), est la probabilite que l'evenement A se realise sachant que l'evenement B est deja realise.

P(A|B) = P(A inter B) / P(B)
Probabilite conditionnelle de A sachant B (P(B) > 0)

Cette formule est l'une des plus importantes en probabilites. Elle exprime que la probabilite de A sachant B est la probabilite de la reunion des deux evenements divisee par la probabilite de B. Autrement dit, on restreint l'univers a B et on calcule la proportion des cas ou A aussi se realise.

Exemple 1 - Urne avec boules colorees

Une urne contient 10 boules : 6 rouges et 4 noires. Parmi les rouges, 3 sont numerotees. Parmi les noires, 2 sont numerotees.

On tire une boule au hasard. Quelle est la probabilite qu'elle soit rouge sachant qu'elle est numerotee ?

Soit R = rouge, N = numerotee.

P(R|N) = P(R inter N)/P(N) = (3/10)/(5/10) = 3/5

Exemple 2 - Maladie et test

Dans une population, 2% des personnes sont malades. Le test detecte la maladie chez 95% des malades, mais donne un faux positif chez 10% des personnes saines.

Probabilite d'etre malade sachant que le test est positif :

Utilisons P(M) = 0,02, P(T|M) = 0,95, P(T|M barre) = 0,10

P(T) = P(T|M)P(M) + P(T|M barre)P(M barre) = 0,95 x 0,02 + 0,10 x 0,98 = 0,117

P(M|T) = P(T|M)P(M)/P(T) = 0,019/0,117 = 0,162 (environ 16,2%)

Meme avec un test positif, il y a moins de 17% de chances d'etre reellement malade !

4.2 Formule des probabilites composees

La probabilite de l'intersection de deux evenements peut s'exprimer en fonction de la probabilite conditionnelle. C'est la formule des probabilites composees, qui est un outil puissant pour les calculs en cascade.

P(A inter B) = P(A) x P(B|A) = P(B) x P(A|B)
Probabilites composees

Cette formule s'etend a plusieurs evenements. Par exemple, pour trois evenements A, B, C : P(A inter B inter C) = P(A) x P(B|A) x P(C|A inter B). On multiplie les probabilites conditionnelles en cascade.

Exemple - Tirages successifs sans remise

Une urne contient 5 boules rouges et 3 boules noires. On tire 3 boules successivement sans remise.

Probabilite d'obtenir 3 rouges :

P(R1 inter R2 inter R3) = (5/8) x (4/7) x (3/6) = 60/336 = 5/28

4.3 Evenements independants

Deux evenements A et B sont dits independants si la realisation de l'un n'affecte pas la probabilite de realisation de l'autre. Cela se traduit mathematiquement par la condition d'egalite entre la probabilite conditionnelle et la probabilite marginale.

P(A|B) = P(A) equivaut a P(B|A) = P(B)
Condition d'independance (equivalente a P(A inter B) = P(A) x P(B))
P(A inter B) = P(A) x P(B)
Condition d'independance (forme multiplicative)

La forme multiplicative P(A inter B) = P(A) x P(B) est la plus utilisee en pratique car elle ne necessite pas de verifier au prealable que P(A) et P(B) sont non nuls. C'est la definition de reference de l'independance.

Attention - Independance vs Incompatibilite

Deux evenements incompatibles (A inter B = ensemble vide) ne sont generalement PAS independants. Si A inter B = ensemble vide, alors P(A inter B) = 0, et l'independance P(A inter B) = P(A) x P(B) ne serait verifiee que si P(A) = 0 ou P(B) = 0. En pratique, deux evenements incompatibles de probabilite non nulle ne sont JAMAIS independants.

4.4 Independance mutuelle de plusieurs evenements

Pour trois evenements A, B, C, on dit qu'ils sont mutuellement independants si toutes les paires sont independantes ET si l'intersection est aussi independante. C'est-a-dire que l'on doit verifier les 4 conditions simultanees.

  • P(A inter B) = P(A) x P(B)
  • P(A inter C) = P(A) x P(C)
  • P(B inter C) = P(B) x P(C)
  • P(A inter B inter C) = P(A) x P(B) x P(C)

Il ne suffit pas que les paires soient independantes pour que les trois evenements soient mutuellement independants. L'independance de l'intersection est une condition supplementaire necessaire.

A retenir

L'independance est une notion mathematique precise. Dire "A n'affecte pas B" ne suffit pas pour affirmer l'independance. Il faut verifier la formule P(A inter B) = P(A) x P(B). En pratique, l'independance est souvent une hypothese du modele (pieces non truquees, tirages avec remise, etc.).

Chapitre 5
Formule des probabilites totales et theoreme de Bayes
5.1 Systeme complet d'evenements

Un ensemble d'evenements {B_1, B_2, ..., B_n} forme un systeme complet d'evenements (ou partition de Omega) s'ils verifient trois conditions : ils sont deux a deux incompatibles, leur reunion est l'univers Omega tout entier, et chacun a une probabilite strictement positive.

B_i inter B_j = ensemble vide pour i different de j
Incompatibilite mutuelle
B_1 union B_2 union ... union B_n = Omega
Couverture de l'univers
P(B_i) > 0 pour tout i
Probabilites strictement positives
Exemple de systeme complet

Dans un lycee, les eleves sont repartis en trois classes : Premiere, Seconde et Terminale. Chaque eleve appartient a exactement une classe. Les ensembles {Premiere, Seconde, Terminale} forment un systeme complet d'evenements.

5.2 Formule des probabilites totales

Soit {B_1, B_2, ..., B_n} un systeme complet d'evenements et A un evenement quelconque. La formule des probabilites totales permet de calculer P(A) en decomposant A selon tous les cas possibles du systeme complet.

P(A) = Somme de i=1 a n de P(A inter B_i) = Somme de i=1 a n de P(B_i) x P(A|B_i)
Formule des probabilites totales

Cette formule est extremement importante. Elle dit que la probabilite d'un evenement A est la somme des probabilites de A intersecte avec chaque element du systeme complet. Chaque terme P(B_i) x P(A|B_i) represente la probabilite que A se realise via le chemin B_i.

Exemple - Usines de production

Trois usines A, B et C produisent des pieces. L'usine A produit 50% des pieces, B 30% et C 20%. Les taux de defaut sont : 2% pour A, 3% pour B et 1% pour C. Quelle est la probabilite qu'une piece choisie au hasard soit defectueuse ?

Soit D = piece defectueuse.

P(D) = P(A)xP(D|A) + P(B)xP(D|B) + P(C)xP(D|C)

P(D) = 0,50 x 0,02 + 0,30 x 0,03 + 0,20 x 0,01 = 0,010 + 0,009 + 0,002 = 0,021

La probabilite qu'une piece soit defectueuse est de 2,1%.

5.3 Theoreme de Bayes

Le theoreme de Bayes permet de "renverser" une probabilite conditionnelle. Si l'on connait P(A|B), le theoreme permet de calculer P(B|A). C'est l'un des theoremes les plus importants en statistiques et en intelligence artificielle.

P(B_i|A) = P(B_i) x P(A|B_i) / P(A)
Theoreme de Bayes (avec formule des probabilites totales pour P(A))

Le theoreme de Bayes est utilise pour calculer la probabilite d'une cause sachant l'effet observe. Par exemple, connaissant le taux de defaut d'une machine et la proportion de pieces produites par cette machine, on peut calculer la probabilite qu'une piece defectueuse provienne de cette machine.

Exemple - Diagnostic medical

Une maladie touche 1% de la population. Un test a une sensibilite de 99% (P(T|M) = 0,99) et une specificite de 95% (P(T barre|M barre) = 0,95, donc P(T|M barre) = 0,05).

Question : Quelle est la probabilite d'etre malade sachant que le test est positif ?

P(M|T) = P(M) x P(T|M) / P(T)

P(T) = P(M) x P(T|M) + P(M barre) x P(T|M barre) = 0,01 x 0,99 + 0,99 x 0,05 = 0,0099 + 0,0495 = 0,0594

P(M|T) = 0,0099 / 0,0594 = 1/6 = 16,7%

Bien que le test soit positif, il n'y a qu'environ 17% de chances d'etre malade !

5.4 Arbre de probabilites

Les arbres de probabilites (ou arbres des probabilites conditionnelles) sont un outil graphique puissant pour visualiser et calculer les probabilites dans les experiences a plusieurs etapes. Chaque noeud represente un evenement, et chaque branche porte la probabilite conditionnelle correspondante.

1
Racine

L'evenement de depart au sommet de l'arbre. Les branches qui partent de la racine portent les probabilites marginales P(B_i)

2
Niveau 2

Apres le premier evenement, chaque branche porte la probabilite conditionnelle P(A|B_i) ou P(A barre|B_i)

3
Feuilles

Les extremites de l'arbre representent les intersections. La probabilite d'un chemin est le produit des probabilites sur ce chemin

Regle de l'arbre

La probabilite d'un chemin est le PRODUIT des probabilites sur les branches de ce chemin. La probabilite d'un evenement est la SOMME des probabilites des chemins menant a cet evenement.

Conseil methodologique

Dessinez toujours un arbre de probabilites dans les exercices a plusieurs etapes (tirages successifs, tests medicaux, chaine de production). Cela rend les calculs beaucoup plus clairs et evite les erreurs. Verifiez toujours que la somme des probabilites sur les branches partant d'un meme noeud vaut 1.

Chapitre 6
Variable aleatoire reelle - Lois de probabilite
6.1 Definition d'une variable aleatoire

Une variable aleatoire reelle (VAR) est une fonction qui associe a chaque issue d'une experience aleatoire un nombre reel. La variable aleatoire transforme ainsi un resultat d'experience (qui peut etre qualitatif) en une valeur numerique, ce qui permet d'effectuer des calculs.

X : Omega flèche vers R
X est une application de l'univers Omega vers l'ensemble des reels R

On distingue deux types de variables aleatoires : les variables discretes qui prennent un nombre fini ou denombrable de valeurs, et les variables continues qui prennent des valeurs dans un intervalle de R. Dans ce cours, nous traitons principalement les variables discretes.

Exemples de variables aleatoires

Lancer d'un de : X = le resultat. X prend les valeurs (1, 2, 3, 4, 5, 6)

Condition de normalisation (la somme de toutes les probabilites vaut 1)

Chapitre 7
Esperance mathematique
7.1 Definition de l'esperance mathematique

L'esperance mathematique d'une variable aleatoire discrete X est la moyenne ponderee de toutes les valeurs que X peut prendre, ou chaque valeur est ponderee par sa probabilite. C'est l'equivalent probabiliste de la moyenne arithmetique. On la note E(X).

E(X) = Somme de i=1 a n de x_i x p_i = x_1 x p_1 + x_2 x p_2 + ... + x_n x p_n
Esperance mathematique

L'esperance represente la valeur moyenne que l'on obtiendrait si l'on repetait l'experience un tres grand nombre de fois. C'est le concept central en theorie des jeux, en assurance et en finance.

Exemple 1 - Gain moyen a un jeu

Un jeu coute 3 euros pour y jouer. On lance un de : si on obtient 6, on gagne 15 euros, sinon on ne gagne rien. Soit X le gain net.

X prend les valeurs : 12 (gain net si 6) et -3 (perte nette sinon)

E(X) = 12 x (1/6) + (-3) x (5/6) = 2 - 2,5 = -0,50

L'esperance est negative (-0,50 euro) : le jeu est defavorable au joueur. En moyenne, on perd 50 centimes par partie.

7.2 Proprietes de l'esperance
E(a) = a pour toute constante a
Esperance d'une constante
E(aX + b) = aE(X) + b
Linearite de l'esperance (a et b constantes)

La propriete de linearite est extremement utile. Elle permet de calculer l'esperance d'une transformation affine de X sans avoir a recalculer toute la loi de probabilite de la nouvelle variable.

Exemple d'application de la linearite

Si E(X) = 3,7, alors : E(2X + 5) = 2 x 3,7 + 5 = 12,4

Si E(X) = -0,5, alors : E(-3X + 1) = -3 x (-0,5) + 1 = 2,5

7.3 Esperance de la somme de variables aleatoires

Pour deux variables aleatoires X et Y (definies sur le meme espace probabilise), l'esperance de leur somme est la somme de leurs esperances. Cette propriete est valable que X et Y soient independantes ou non.

E(X + Y) = E(X) + E(Y)
Additivite de l'esperance (sans condition d'independance)

Si X et Y sont independantes, on a aussi la propriete de multiplicativite : E(X x Y) = E(X) x E(Y). Attention, cette derniere formule n'est valable QUE si X et Y sont independantes.

7.4 Interpretation de l'esperance

L'esperance a plusieurs interpretations importantes qui aident a comprendre sa signification dans les exercices et les applications pratiques :

  • Loi des grands nombres : Si l'on repete l'experience n fois et que S_n est la somme des resultats, alors S_n/n tend vers E(X) quand n tend vers l'infini. C'est la loi faible des grands nombres
  • Jeu equitable : Un jeu est dit equitable lorsque l'esperance du gain net est nulle, c'est-a-dire E(X) = 0. Le joueur n'est ni avantage ni desavantage sur le long terme
  • Indicateur de centralite : L'esperance est le centre de gravite de la distribution de probabilite. Elle indique autour de quelle valeur les resultats se concentrent
Attention

L'esperance n'est pas forcement une valeur que X peut prendre. Par exemple, si X est le resultat d'un de equitable, E(X) = 3,5, qui n'est pas une face du de. L'esperance est une moyenne theorique, pas un resultat possible.

7.5 Esperance d'un indicateur

Un cas frequent en probabilites est celui d'un indicatrice (variable de Bernoulli). Si A est un evenement et X = 1_A (X vaut 1 si A se realise, 0 sinon), alors l'esperance de X est simplement la probabilite de A.

E(1_A) = P(A)
Esperance d'une variable indicatrice

Cette propriete est extremement utile pour calculer l'esperance d'une variable qui compte le nombre de realisations d'un evenement. Si X = X_1 + X_2 + ... + X_n ou chaque X_i est une indicatrice, alors E(X) = P(A_1) + P(A_2) + ... + P(A_n).

Conseil pratique

Pour calculer l'esperance d'une somme de variables de comptage, decomposez chaque variable en somme d'indicatrices. Cette technique (dite de linearite de l'esperance) evite de calculer la loi de la somme, qui peut etre tres complexe.

Chapitre 8
Variance et ecart-type
8.1 Definition de la variance

La variance d'une variable aleatoire X mesure la dispersion des valeurs de X autour de son esperance. Plus la variance est grande, plus les valeurs de X sont etalees autour de la moyenne. Plus elle est petite, plus les valeurs sont concentrees pres de la moyenne. On la note Var(X) ou V(X).

Var(X) = Somme de i=1 a n de (x_i - E(X)) carre x p_i
Variance (definition)

La variance est la moyenne ponderee des carres des ecarts a l'esperance. Le carre est utilise pour eviter que les ecarts positifs et negatifs ne s'annulent mutuellement.

8.2 Formule de Koenig-Huygens (formule pratique)

En pratique, on utilise plus souvent la formule de Koenig-Huygens (aussi appelee theoreme de Steiner) qui est une forme equivalente mais beaucoup plus pratique a calculer. Elle evite de calculer les ecarts individuels a l'esperance.

Var(X) = E(X carre) - [E(X)] carre
Formule de Koenig-Huygens

ou E(X carre) = Somme de x_i carre x p_i est le moment d'ordre 2. Cette formule est la plus utilisee en pratique car elle ne necessite qu'une seule operation de soustraction au lieu de calculer n ecarts.

1
Etape 1

Calculer E(X) = Somme de x_i x p_i

2
Etape 2

Calculer E(X carre) = Somme de (x_i au carre) x p_i

3
Etape 3

Appliquer : Var(X) = E(X carre) - [E(X)] au carre

Exemple detaille

Soit X de loi : P(X=0)=0,2, P(X=1)=0,5, P(X=2)=0,3

Etape 1 : E(X) = 0 x 0,2 + 1 x 0,5 + 2 x 0,3 = 0 + 0,5 + 0,6 = 1,1

Etape 2 : E(X carre) = 0 x 0,2 + 1 x 0,5 + 4 x 0,3 = 0 + 0,5 + 1,2 = 1,7

Etape 3 : Var(X) = 1,7 - 1,1 x 1,1 = 1,7 - 1,21 = 0,49

8.3 Proprietes de la variance
Var(a) = 0 pour toute constante a
La variance d'une constante est nulle
Var(aX + b) = a carre x Var(X)
La variance est affectee par le carre du coefficient

Contrairement a l'esperance, la variance n'est pas lineaire. Si l'on multiplie X par a, la variance est multipliee par a au carre (et non par a). L'addition d'une constante b ne modifie pas la variance, car la dispersion n'est pas affectee par une translation.

Exemples d'application

Si Var(X) = 4 :

Var(3X + 2) = 9 x Var(X) = 9 x 4 = 36

Var(-X) = (-1) au carre x Var(X) = 4 (la multiplication par -1 ne change pas la variance)

Var(X + 10) = Var(X) = 4 (ajouter une constante ne change pas la dispersion)

8.4 Ecart-type

L'ecart-type d'une variable aleatoire est la racine carree de la variance. Il s'exprime dans la meme unite que la variable X, ce qui le rend plus interpretable que la variance (qui est dans le carre de l'unite).

sigma(X) = racine carree de Var(X)
Ecart-type

L'ecart-type est la mesure de dispersion la plus utilisee en statistiques et en probabilites. Il permet de comparer la dispersion de differentes variables aleatoires de maniere homogene.

Calcul de l'ecart-type

Si Var(X) = 0,49 (exemple precedent) :

sigma(X) = racine carree de 0,49 = 0,7

L'ecart-type est de 0,7, ce qui signifie que les valeurs de X s'ecartent en moyenne de 0,7 par rapport a l'esperance (1,1).

8.5 Variance d'une somme de variables
Var(X + Y) = Var(X) + Var(Y) + 2 x Cov(X,Y)
Cas general
Var(X + Y) = Var(X) + Var(Y)
Cas ou X et Y sont independantes (Cov(X,Y) = 0)

La covariance Cov(X,Y) = E(XY) - E(X)E(Y) mesure la dependance lineaire entre X et Y. Si les variables sont independantes, la covariance est nulle et les variances s'ajoutent simplement.

Formules a connaitre par coeur

E(X) pour le centre, Var(X) = E(X^2) - [E(X)]^2 pour la dispersion, sigma = racine de Var pour l'ecart-type. Ces trois formules suffisent pour resoudre la grande majorite des exercices.

Chapitre 9
Fonction de repartition
9.1 Definition de la fonction de repartition

La fonction de repartition d'une variable aleatoire X, notee F_X ou simplement F, associe a tout reel x la probabilite que X prenne une valeur inferieure ou egale a x. C'est un outil fondamental qui decrit completement la loi de probabilite d'une variable aleatoire.

F(x) = P(X inferieur ou egal a x)
Fonction de repartition
9.2 Proprietes de la fonction de repartition
  • F est une fonction croissante : si a inferieur a b, alors F(a) inferieur ou egal a F(b)
  • limite quand x tend vers -infini de F(x) = 0 (quand x est tres negatif, il n'y a presque aucune chance que X soit inferieur a x)
  • limite quand x tend vers +infini de F(x) = 1 (quand x est tres grand, X est presque surement inferieur a x)
  • F est continue a droite en tout point
  • P(X = a) = F(a) - F(a-) = F(a) - limite a gauche de F en a
9.3 Construction de la fonction de repartition

Pour une variable discrete, on construit F pas a pas. On classe les valeurs de X par ordre croissant, puis on accumule les probabilites. La fonction F est une fonction en escalier (constante par morceaux, avec des sauts aux valeurs de X).

1
Trier les valeurs

Classer les valeurs x_1 < x_2 < ... < x_n par ordre croissant

2
Calculer les sauts

F(x_i) = P(X inferieur ou egal a x_i) = somme des p_j pour j de 1 a i

3
Decrire F

F(x) = 0 pour x < x_1, F(x) = p_1 pour x_1 inferieur ou egal a x < x_2, etc., F(x) = 1 pour x superieur ou egal a x_n

Exemple complet

Soit X de loi : P(X=-1)=0,2, P(X=0)=0,3, P(X=2)=0,4, P(X=5)=0,1

Calcul de F :

Pour x < -1 : F(x) = 0

Pour -1 inferieur ou egal a x < 0 : F(x) = 0,2

Pour 0 inferieur ou egal a x < 2 : F(x) = 0,2 + 0,3 = 0,5

Pour 2 inferieur ou egal a x < 5 : F(x) = 0,5 + 0,4 = 0,9

Pour x superieur ou egal a 5 : F(x) = 0,9 + 0,1 = 1

9.4 Calcul de probabilites avec F

La fonction de repartition permet de calculer facilement toutes les probabilites d'intervalles :

P(a < X inferieur ou egal a b) = F(b) - F(a)
Probabilite d'un intervalle semi-ouvert
P(X > a) = 1 - F(a)
Probabilite de depasser a
P(X = a) = F(a) - F(a-) = taille du saut en a
Probabilite d'un point

Ces formules montrent que toute la loi de probabilite est encodee dans la fonction de repartition. C'est pourquoi F est si importante en theorie des probabilites.

9.5 Representation graphique

La representation graphique de F pour une variable discrete est une courbe en escalier. Chaque marche correspond a une valeur de X, et la hauteur de la marche est la probabilite de cette valeur. Cette representation permet de visualiser rapidement la distribution des probabilites.

Utilite de F

La fonction de repartition est utilisee dans les exercices pour calculer P(a < X inferieur ou egal a b) = F(b) - F(a). Elle est aussi indispensable pour definir les lois continues, ou la probabilite d'un point est nulle et seul le calcul d'intervalles a un sens.

Loi binomiale
10.1 Epreuve de Bernoulli

Une epreuve de Bernoulli est une experience aleatoire qui n'a que deux issues possibles : un succes (note S) avec probabilite p, et un echec (note E) avec probabilite q = 1 - p. C'est le modele le plus simple en probabilites.

P(S) = p et P(E) = 1 - p = q
Epreuve de Bernoulli de parametre p
Exemples d'epreuves de Bernoulli

Lancer une piece : Succes = Pile (p = 1/2), Echec = Face (q = 1/2)

Controler un produit : Succes = conforme (p = 0,97), Echec = defectueux (q = 0,03)

Tirer une carte : Succes = As (p = 4/32 = 1/8), Echec = non-As (q = 7/8)

Repondre a un QCM : Succes = bonne reponse (p = 1/4), Echec = mauvaise reponse (q = 3/4)

10.2 Loi de Bernoulli

Soit X la variable aleatoire qui vaut 1 en cas de succes et 0 en cas d'echec. X suit la loi de Bernoulli de parametre p. C'est le modele de variable aleatoire le plus simple, mais aussi le plus fondamental.

x_i01
P(X=x_i)1-pp
E(X) = p
Esperance d'une loi de Bernoulli
Var(X) = p(1-p) = pq
Variance d'une loi de Bernoulli
10.3 Schema de Bernoulli

Un schema de Bernoulli est la repetition n fois, de maniere independante, d'une meme epreuve de Bernoulli de parametre p. A chaque repetition, la probabilite de succes reste p, et les resultats des differentes repetitions sont independants les uns des autres.

L'independance des repetitions est essentielle : le resultat d'une epreuve ne doit pas influencer les suivantes. C'est le cas des tirages avec remise, des lancers successifs d'un de non pipe, etc.

10.4 Loi binomiale

Soit X la variable aleatoire qui compte le nombre de succes dans un schema de Bernoulli de n repetitions. X suit la loi binomiale de parametres n et p, notee B(n, p).

P(X = k) = C(n,k) x p puissance k x (1-p) puissance (n-k)
Loi binomiale B(n, p)

Cette formule donne la probabilite d'obtenir exactement k succes parmi n repetitions independantes. Le terme C(n,k) compte le nombre de facons de choisir les k positions des succes parmi n, p puissance k est la probabilite d'avoir k succes, et (1-p) puissance (n-k) est la probabilite d'avoir n-k echecs.

Exemple - 10 lancers d'une piece equilibree

On lance une piece 10 fois. X = nombre de piles. X suit B(10, 1/2).

P(X = 5) = C(10,5) x (1/2) puissance 5 x (1/2) puissance 5 = 252 x 1/1024 = 63/256 = 0,246

P(X = 0) = C(10,0) x (1/2) puissance 10 = 1/1024 = 0,00098

P(X = 10) = C(10,10) x (1/2) puissance 10 = 1/1024 = 0,00098

10.5 Proprietes de la loi binomiale
E(X) = np
Esperance de la loi binomiale
Var(X) = np(1-p) = npq
Variance de la loi binomiale
sigma(X) = racine carree de np(1-p)
Ecart-type

L'esperance np est le nombre moyen de succes attendu sur n repetitions. La variance npq mesure la dispersion autour de cette moyenne.

10.6 Conditions d'application
Quand utiliser la loi binomiale

La loi binomiale s'applique quand les 4 conditions sont reunies : (1) On repete n fois la meme experience, (2) Chaque experience a 2 issues (succes/echec), (3) La probabilite p de succes est constante, (4) Les experiences sont independantes.

Pour les calculs, on utilise souvent une calculatrice ou une table de la loi binomiale. Les calculatrices scientifiques proposent generalement les fonctions binomPdf (probabilite exacte P(X=k)) et binomCdf (probabilite cumulee P(X inferieur ou egal a k)).

a) X suit la loi binomiale B(8, 0,3).

b) Probabilite qu'exactement 3 personnes preferent le the :

Chapitre 11
Loi de Poisson
11.1 Introduction a la loi de Poisson

La loi de Poisson (du mathematicien Simeon Denis Poisson) modelise le nombre d'evenements rares se produisant dans un intervalle donne (temps, espace, etc.) lorsque les evenements se produisent independamment les uns des autres a un taux moyen constant.

Elle est aussi appelee loi des evenements rares car elle decrit des phenomenes qui se produisent peu frequemment mais de maniere reguliere : appels telephoniques dans un standard, erreurs de frappe dans un texte, pannes de machines, arrivées de clients dans une file d'attente, accidents routiers, etc.

11.2 Definition de la loi de Poisson

Une variable aleatoire X suit la loi de Poisson de parametre lambda (lambda > 0), notee P(lambda), si pour tout entier k superieur ou egal a 0 :

P(X = k) = (e puissance -lambda) x (lambda puissance k) / k!
Loi de Poisson P(lambda)

ou e est la base du logarithme neperien (e = 2,71828...), lambda est le parametre de la loi (nombre moyen d'evenements), et k! est la factorielle de k.

Exemples de situations poissonniennes

Appels telephoniques : Un standard recoit en moyenne 5 appels par minute. X = nombre d'appels en 1 minute suit P(5)

Erreurs de frappe : En moyenne 2 erreurs par page. X = nombre d'erreurs par page suit P(2)

Pannes de machines : En moyenne 0,5 panne par jour. X = nombre de pannes par jour suit P(0,5)

11.3 Proprietes de la loi de Poisson
E(X) = lambda
Esperance (nombre moyen d'evenements)
Var(X) = lambda
Variance (egale a l'esperance !)

La propriete Var(X) = E(X) = lambda est caracteristique de la loi de Poisson. Si l'on observe que la variance d'un phenomene est environ egale a sa moyenne, il y a de fortes chances qu'il suive une loi de Poisson.

11.4 Approximation de la binomiale par la loi de Poisson

Lorsque n est grand et p est petit (evenements rares), la loi binomiale B(n, p) peut etre approchee par la loi de Poisson P(lambda) avec lambda = np. C'est le theoreme de Poisson (cas limite de la loi binomiale).

Si n grand, p petit, np = lambda modere, alors B(n,p) est approchee par P(lambda = np)
Approximation de Poisson

En pratique, on utilise cette approximation quand n superieur ou egal a 30 et p inferieur ou egal a 0,1 (certains auteurs donnent np inferieur ou egal a 5 comme critere supplementaire). L'approximation est d'autant meilleure que n est grand et p est petit.

Exemple d'approximation

Une usine produit 1000 pieces par jour. La probabilite qu'une piece soit defectueuse est 0,005. Soit X le nombre de pieces defectueuses par jour.

X suit B(1000, 0,005). Comme n = 1000 est grand et p = 0,005 est petit :

On approche par P(lambda) avec lambda = 1000 x 0,005 = 5.

Probabilite qu'il y ait exactement 3 pieces defectueuses :

P(X=3) environ e puissance (-5) x 5 puissance 3 / 3! = 0,0067 x 125 / 6 = 0,1404

Calcul exact avec la binomiale : P(X=3) = C(1000,3) x 0,005 puissance 3 x 0,995 puissance 997 = 0,1404 (identique a 10 puissance -4 pres)

Attention

L'approximation de Poisson n'est valable QUE si p est petit. Si p est grand (par exemple p = 0,5), l'approximation de Poisson est tres mauvaise et il vaut mieux utiliser la loi binomiale directement ou l'approximation normale.

11.5 Additivite de la loi de Poisson

Si X et Y sont deux variables aleatoires independantes suivant respectivement P(lambda_1) et P(lambda_2), alors X + Y suit la loi P(lambda_1 + lambda_2). Cette propriete d'additivite est tres pratique pour combiner des evenements poissonniens.

Application

Un magasin recoit en moyenne 3 clients par heure le matin et 5 clients par heure l'apres-midi. Le nombre de clients par jour suit P(3 + 5) = P(8) si les arrivees matin et apres-midi sont independantes.

A retenir

La loi de Poisson modelise les evenements rares. Son parametre lambda est a la fois la moyenne et la variance. Elle sert aussi a approximer la loi binomiale quand n est grand et p est petit.

Chapitre 12
Loi hypergeometrique et loi geometrique
12.1 Loi hypergeometrique

La loi hypergeometrique modelise le nombre de succes lors de tirages successifs sans remise dans une population de taille N contenant K individus presentant le caractere etudie. Contrairement a la loi binomiale (tirages avec remise), ici la probabilite change a chaque tirage.

P(X = k) = C(K,k) x C(N-K, n-k) / C(N, n)
Loi hypergeometrique H(N, K, n)

N = taille de la population, K = nombre d'individus ayant le caractere, n = nombre de tirages, k = nombre de succes observes. On choisit k individus parmi les K individus avec le caractere, et n-k individus parmi les N-K individus sans le caractere.

Exemple - Loterie

Dans un lot de 20 pieces, 3 sont defectueuses. On tire 5 pieces sans remise. Quelle est la probabilite d'obtenir exactement 1 piece defectueuse ?

P(X=1) = C(3,1) x C(17,4) / C(20,5) = 3 x 2380 / 15504 = 7140/15504 = 0,4605

Il y a environ 46% de chances d'obtenir exactement 1 piece defectueuse.

12.2 Proprietes de la loi hypergeometrique
E(X) = n x K/N
Esperance (identique a la binomiale np avec p = K/N)

L'esperance de la loi hypergeometrique est la meme que celle de la binomiale B(n, K/N). Cependant, la variance est differente (elle est plus petite car le tirage sans remise reduit la variabilite).

Var(X) = n x (K/N) x (1 - K/N) x (N-n)/(N-1)
Variance hypergeometrique

Le facteur (N-n)/(N-1) est le facteur de correction pour population finie. Quand N est grand par rapport a n, ce facteur est proche de 1 et la loi hypergeometrique se rapproche de la loi binomiale.

12.3 Approximation par la loi binomiale

Quand N est grand et n/N est petit (tirage d'un petit echantillon dans une grande population), la loi hypergeometrique H(N, K, n) peut etre approchee par la loi binomiale B(n, p = K/N).

Regle pratique

On approche H(N,K,n) par B(n, K/N) quand n/N inferieur ou egal a 0,1 (la taille de l'echantillon ne depasse pas 10% de la population). C'est une approximation tres utilisee dans les sondages.

12.4 Loi geometrique

La loi geometrique modelise le nombre d'essais necessaires pour obtenir le premier succes dans une suite d'epreuves de Bernoulli independantes de parametre p. C'est le temps d'attente du premier succes.

P(X = k) = (1-p) puissance (k-1) x p = q puissance (k-1) x p
Loi geometrique de parametre p, pour k = 1, 2, 3, ...

La probabilite que le premier succes arrive au k-ieme essai est : on a eu k-1 echecs consecutifs puis un succes. La probabilite de k-1 echecs est q puissance (k-1), et la probabilite du succes suivant est p.

Exemples d'utilisation

Jeu de des : Nombre de lancers necessaires pour obtenir un 6. Si le de est equitable, X suit la loi geometrique de parametre p = 1/6.

Probabilite que le premier 6 arrive au 3eme lancer : P(X=3) = (5/6) au carre x (1/6) = 25/216 = 0,1157

Tir a l'arc : Nombre de tirs jusqu'au premier impact au centre. Si la probabilite de toucher le centre est 0,15, X suit G(0,15).

12.5 Proprietes de la loi geometrique
E(X) = 1/p
Esperance : en moyenne 1/p essais pour le premier succes
Var(X) = (1-p)/p au carre = q/p au carre
Variance

L'esperance 1/p est intuitive : si la probabilite de succes est p, il faut en moyenne 1/p essais pour obtenir un succes. Par exemple, si p = 0,25, il faut en moyenne 4 essais.

P(X > k) = (1-p) puissance k = q puissance k
Probabilite que le premier succes arrive apres le k-ieme essai
Conseil

Pour identifier si une situation suit une loi geometrique, cherchez la notion de "temps d'attente" ou "nombre d'essais jusqu'au premier succes". Si c'est le cas, et que les essais sont independants avec la meme probabilite p, alors c'est une loi geometrique.

Chapitre 13
Loi uniforme et lois continues
13.1 Variables aleatoires continues

Une variable aleatoire est dite continue si elle peut prendre n'importe quelle valeur dans un intervalle (ou une reunion d'intervalles) de nombres reels. Contrairement aux variables discretes, la probabilite qu'une variable continue prenne une valeur precise est nulle. On ne peut calculer que des probabilites d'intervalles.

P(X = a) = 0 pour tout reel a
Probabilite ponctuelle nulle pour une variable continue
13.2 Densite de probabilite

Pour decrire la loi d'une variable aleatoire continue, on utilise une fonction appelee densite de probabilite, notee f. Cette fonction est positive et son integrale sur tout l'ensemble reel vaut 1.

f(x) superieur ou egal a 0 pour tout x
Positivite de la densite
Integrale de -infini a +infini de f(x) dx = 1
Normalisation (aire totale = 1)

La probabilite que X appartienne a un intervalle [a, b] est l'aire sous la courbe de f entre a et b :

P(a inferieur ou egal a X inferieur ou egal a b) = Integrale de a a b de f(x) dx
Probabilite d'un intervalle
13.3 Fonction de repartition d'une variable continue

Pour une variable continue, la fonction de repartition est definie par :

F(x) = P(X inferieur ou egal a x) = Integrale de -infini a x de f(t) dt
Fonction de repartition continue

Contrairement au cas discret, F est ici une fonction continue (sans sauts). La densite f est la derivee de F : f(x) = F'(x). La probabilite d'un intervalle se calcule aussi par : P(a < X inferieur ou egal a b) = F(b) - F(a).

13.4 Esperance et variance d'une variable continue
E(X) = Integrale de -infini a +infini de x f(x) dx
Esperance d'une variable continue
Var(X) = Integrale de -infini a +infini de (x - E(X)) au carre f(x) dx = E(X au carre) - [E(X)] au carre
Variance
13.5 Loi uniforme sur [a, b]

La loi uniforme sur un intervalle [a, b] est la loi continue la plus simple. Toutes les valeurs de l'intervalle [a, b] sont equiprobables. La densite est constante sur [a, b] et nulle en dehors.

f(x) = 1/(b-a) pour x dans [a, b], et f(x) = 0 sinon
Densite de la loi uniforme U[a, b]
E(X) = (a + b) / 2
Esperance : milieu de l'intervalle
Var(X) = (b - a) au carre / 12
Variance
Exemple - Bus

Un bus passe a un arret toutes les 15 minutes. Un passager arrive a un instant aleatoire uniformement reparti sur [0, 15]. Soit X le temps d'attente en minutes.

X suit la loi uniforme U[0, 15].

E(X) = (0+15)/2 = 7,5 minutes (temps d'attente moyen)

Probabilite d'attendre moins de 5 minutes : P(X < 5) = 5/15 = 1/3

Probabilite d'attendre plus de 10 minutes : P(X > 10) = 5/15 = 1/3

13.6 Loi exponentielle

La loi exponentielle de parametre lambda (lambda > 0) modelise les durees de vie ou les temps d'attente entre deux evenements dans un processus de Poisson. Elle est souvent utilisee en fiabilite et en theorie des files d'attente.

f(x) = lambda x e puissance (-lambda x) pour x superieur ou egal a 0
Loi exponentielle de parametre lambda
E(X) = 1/lambda
Esperance (duree de vie moyenne)
Var(X) = 1/lambda au carre
Variance
P(X > t) = e puissance (-lambda t)
Probabilite de survie au-dela de t

La propriete d'absence de memoire est unique a la loi exponentielle : P(X > s + t | X > s) = P(X > t). La duree de vie residuelle ne depend pas de la duree deja vecue.

A retenir

Loi uniforme = equiprobabilite continue sur un intervalle. Loi exponentielle = temps d'attente dans un processus de Poisson. Les deux sont des lois continues fondamentales au programme.

Chapitre 14
Couple de variables aleatoires
14.1 Couple de variables aleatoires discretes

Dans de nombreux exercices, on considere simultanement deux variables aleatoires X et Y definies sur le meme espace probabilise. Le couple (X, Y) est lui-meme une variable aleatoire a valeurs dans le produit cartesien des ensembles de valeurs de X et Y.

14.2 Loi jointe d'un couple

La loi jointe du couple (X, Y) est la donnee de toutes les probabilites P(X = x_i et Y = y_j) pour toutes les valeurs possibles x_i de X et y_j de Y. On la represente par un tableau a double entree appele tableau de contingence.

Exemple de loi jointe

Soient X et Y definies par le tableau suivant :

Y / X01Total
00,20,30,5
10,10,20,3
20,10,10,2
Total0,40,61,0

Verification : la somme de toutes les cases = 1.

14.3 Lois marginales

Les lois marginales de X et Y sont les lois de probabilite de X et Y prises separement. Elles s'obtiennent en sommant les probabilites de la loi jointe.

P(X = x_i) = Somme sur j de P(X = x_i et Y = y_j)
Loi marginale de X (somme en ligne)
P(Y = y_j) = Somme sur i de P(X = x_i et Y = y_j)
Loi marginale de Y (somme en colonne)

Dans le tableau de contingence, les lois marginales se trouvent dans la derniere ligne (pour X) et la derniere colonne (pour Y). On les appelle les "distributions marginales".

14.4 Lois conditionnelles

Les lois conditionnelles de Y sachant X = x_i sont les lois de probabilite de Y pour chaque valeur fixee de X. Elles s'obtiennent en divisant chaque case par le total de la ligne correspondante.

P(Y = y_j | X = x_i) = P(X = x_i et Y = y_j) / P(X = x_i)
Loi conditionnelle de Y sachant X = x_i
14.5 Independance de deux variables aleatoires

Deux variables X et Y sont independantes si et seulement si pour tous les couples (x_i, y_j), la probabilite jointe est egale au produit des probabilites marginales.

P(X = x_i et Y = y_j) = P(X = x_i) x P(Y = y_j) pour tous les i, j
Condition d'independance

Pour verifier l'independance, il suffit de trouver UN SEUL couple (x_i, y_j) qui ne verifie pas cette egalite pour affirmer que X et Y ne sont pas independantes. Pour prouver l'independance, il faut verifier la condition pour TOUS les couples.

14.6 Covariance et correlation

La covariance de X et Y mesure la dependance lineaire entre les deux variables. Le coefficient de correlation est la version normalisee de la covariance.

Cov(X, Y) = E(XY) - E(X)E(Y)
Covariance
r(X, Y) = Cov(X, Y) / [sigma(X) x sigma(Y)]
Coefficient de correlation lineaire

La correlation est toujours comprise entre -1 et 1. Plus elle est proche de 1 ou -1, plus la dependance lineaire est forte. Une correlation de 0 signifie qu'il n'y a pas de dependance lineaire (mais il peut y avoir une dependance non lineaire).

Cov(X,Y) = 0 si X et Y independantes
Propriete (la reciproque est fausse en general)
Points importants

Independance implique covariance nulle, mais covariance nulle n'implique PAS independance. Pour l'independance, il faut verifier P(X=x, Y=y) = P(X=x) x P(Y=y) pour tous les couples.

Chapitre 15
Theoreme central limite et loi normale
15.1 Theoreme central limite (TCL)

Le theoreme central limite est l'un des resultats les plus importants en probabilites et en statistiques. Il affirme que la somme (ou la moyenne) d'un grand nombre de variables aleatoires independantes et identiquement distribuees tend vers une loi normale, quelle que soit la loi initiale des variables.

Si X_1, X_2, ..., X_n sont i.i.d. de moyenne m et variance sigma au carre, alors (S_n - n m) / (sigma x racine de n) tend vers N(0,1) quand n tend vers l'infini
Theoreme central limite

Ce theoreme explique pourquoi la loi normale est si omnipresente dans la nature : des phenomenes qui resultent de l'addition de nombreux petits facteurs independants tendent naturellement vers une distribution normale. C'est le cas de la taille des individus, des erreurs de mesure, des fluctuations financieres, etc.

15.2 Loi normale (gaussienne)

Une variable aleatoire X suit la loi normale (ou loi de Gauss, ou loi de Laplace-Gauss) de parametres m et sigma, notee N(m, sigma au carre), si sa densite de probabilite est :

f(x) = (1 / (sigma x racine de 2 pi)) x e puissance (-(x-m) au carre / (2 sigma au carre))
Densite de la loi normale N(m, sigma au carre)

La courbe de cette densite est en forme de cloche (courbe de Gauss), symetrique par rapport a m. Le parametre m est le centre de la distribution (la moyenne) et sigma mesure la dispersion (ecart-type). Environ 68% des valeurs sont dans [m - sigma, m + sigma], et environ 95% dans [m - 2 sigma, m + 2 sigma].

E(X) = m
La moyenne est le premier parametre
Var(X) = sigma au carre
La variance est le carre du second parametre
15.3 Loi normale centree reduite

La loi normale centree reduite N(0, 1) est la loi normale de moyenne 0 et d'ecart-type 1. Toute loi normale peut etre ramenee a la loi centree reduite par le changement de variable :

Z = (X - m) / sigma suit N(0, 1) si X suit N(m, sigma au carre)
Centrage et reduction

Les tables de la loi normale ne sont tabulees que pour la loi centree reduite. Pour calculer des probabilites pour une loi normale quelconque, on commence par centrer et reduire, puis on utilise la table.

15.4 Calcul pratique avec la loi normale
Exemple type

La taille des hommes adultes suit N(175 cm, 49 cm carre), donc m = 175 et sigma = 7.

a) Probabilite qu'un homme mesure entre 168 et 182 cm :

Z1 = (168 - 175) / 7 = -1, Z2 = (182 - 175) / 7 = 1

P(168 inferieur ou egal a X inferieur ou egal a 182) = P(-1 inferieur ou egal a Z inferieur ou egal a 1) = Phi(1) - Phi(-1) = 0,8413 - 0,1587 = 0,6827

b) Probabilite qu'un homme mesure plus de 190 cm :

Z = (190 - 175) / 7 = 2,14

P(X > 190) = P(Z > 2,14) = 1 - Phi(2,14) = 1 - 0,9838 = 0,0162

15.5 Approximation normale de la binomiale

Lorsque n est grand et p n'est pas trop proche de 0 ou 1, la loi binomiale B(n, p) peut etre approchee par la loi normale N(np, npq). C'est le theoreme de Moivre-Laplace :

B(n, p) est approchee par N(np, np(1-p)) quand n est grand
Approximation normale de la binomiale

En pratique, cette approximation est satisfaisante quand n superieur ou egal a 30 et np superieur ou egal a 5 et n(1-p) superieur ou egal a 5. On utilise souvent la correction de continuite : P(X = k) est approche par P(k - 0,5 inferieur ou egal a Y inferieur ou egal a k + 0,5) ou Y suit N(np, npq).

Approximation normale

On lance 100 fois une piece equilibree. X = nombre de piles suit B(100, 0,5).

On approche par N(50, 25), donc N(50, 5 au carre), avec sigma = 5.

Probabilite d'obtenir entre 45 et 55 piles :

P(44,5 inferieur ou egal a Y inferieur ou egal a 55,5) (avec correction de continuite)

= P((44,5-50)/5 inferieur ou egal a Z inferieur ou egal a (55,5-50)/5)

= P(-1,1 inferieur ou egal a Z inferieur ou egal a 1,1) = Phi(1,1) - Phi(-1,1) = 0,8643 - 0,1357 = 0,7286

Regle pratique

Loi binomiale B(n,p) : si p petit, utiliser l'approximation de Poisson. Si n grand et np et n(1-p) grands, utiliser l'approximation normale. Sinon, calculer directement avec la formule binomiale.
