Exercice 6 : Verifier les proprietes

Ces proprietes sont fondamentales et definissent la fonction exponentielle.

Exercice 12 : Etude de f(x) = ex + e-x

a) Montrons que f(-x) = f(x) :

Exercice 13 Correction

Exercice 13 : Resoudre les inequations

a) e2x - 4ex + 3 < 0

On pose X = ex > 0. On obtient X2 - 4X + 3 < 0.

Delta = 16 - 12 = 4. Racines : X = (4-2)/2 = 1 et X = (4+2)/2 = 3.

Le trinome est negatif entre les racines : 1 < X < 3.

Donc 1 < ex < 3, soit 0 < x < ln(3). S = ]0 ; ln(3)[.

b) ex + e-x > 2

D'apres l'exercice 12, on sait que ex + e-x >= 2 avec egalite si et seulement si x = 0.

Donc l'inequation est satisfaite pour tout x different de 0. S = R* (R \ {0}).

c) ex > 1/x

Cette inequation se resout par etude graphique ou par analyse de la fonction g(x) = ex - 1/x.

Pour x > 0 : ex croit tres vite et 1/x decroit. On montre que ex > 1/x pour tout x > 0 (etude de g).

Pour x < 0 : ex > 0 et 1/x < 0, donc l'inegalite est toujours vraie.

S = ]-infini ; 0[ U ]0 ; +infini[ = R*.

Exercice 14 Correction

Exercice 14 : Systeme d'equations

Systeme : ex + ey = e + 1 et ex . ey = e

On pose X = ex > 0 et Y = ey > 0. Le systeme devient :

X + Y = e + 1 et X . Y = e

X et Y sont les solutions de l'equation t2 - (e+1)t + e = 0.

Delta = (e+1)2 - 4e = e2 + 2e + 1 - 4e = e2 - 2e + 1 = (e-1)2.

t = ((e+1) - (e-1))/2 = 2/2 = 1 ou t = ((e+1) + (e-1))/2 = 2e/2 = e.

Donc (X, Y) = (e, 1) ou (X, Y) = (1, e).

Si X = e, Y = 1 : ex = e donc x = 1, et ey = 1 donc y = 0.

Si X = 1, Y = e : ex = 1 donc x = 0, et ey = e donc y = 1.

Solutions : (x, y) = (1, 0) ou (x, y) = (0, 1).
