Sens direct : si ABC equilateral, on a b - a = omega(c - a) avec omega = eipm 2ipi/3.
On montre (comme ex 106) que a2 + b2 + c2 = ab + bc + ca.
Sens reciproque : si a2 + b2 + c2 = ab + bc + ca, alors (a-b)2 + (b-c)2 + (c-a)2 = 0.
On pose X = a-b, Y = b-c, Z = c-a = -(X+Y). X2 + Y2 + (X+Y)2 = 2(X2 + XY + Y2) = 0.
Donc X/Y est racine de t2 + t + 1 = 0, soit X/Y = omega ou omega2.
Donc (a-b)/(b-c) = omega ou omega2, ce qui montre que ABC est equilateral. CQFD.

Soient zk = ei2kpi/7 pour k = 1, 2, ..., 6 les racines 7-iemes de l'unite (sauf 1).
On a z7 - 1 = (z - 1)(z6 + z5 + ... + z + 1) = 0.

Donc 2[cos(2pi/7) + cos(4pi/7) + cos(6pi/7)] = -1.
