La miniature est l element le plus important de votre video pour le CTR. Avant meme de lire le titre, le spectateur voit la miniature. Une miniature optimisee peut multiplier votre CTR par 3 a 5 fois. Voici les principes a suivre pour creer des miniatures qui font cliquer.

Miniature Faible
  • Image trop chargee avec 10+ elements
  • Texte illisible en petite taille (moins de 40px)
  • Pas de visage humain ou expression neutre
  • Couleurs fades ou contraste insuffisant
  • Texte qui repete le titre (redondant)
  • Image generique de stock sans personnalite
Miniature Forte
  • Maximum 3 elements visuels (visage, objet, texte)
  • Texte court et lisible (2-5 mots maximum)
  • Visage avec emotion forte (surprise, joie, curiosite)
  • Contraste eleve : fond sombre + elements clairs (ou inverse)
  • Texte qui complete le titre (pas de repetition)
  • Image unique qui raconte une histoire en un coup d oeil
  • Dimensions - 1280 x 720 pixels minimum, ratio 16:9. YouTube recadre automatiquement : verifiez le rendu en 168 x 94 px (resultats de recherche) et en 464 x 259 px (page d accueil). Le texte doit rester lisible dans toutes les tailles.
  • Emotions - Les visages avec des emotions fortes generent 30% de clics en plus. Surprenez-vous, souriez largement, montrez de la curiosite. L oeil humain est programme pour reagir aux expressions faciales, surtout les emotions extremes.
  • Couleurs - Utilisez 2 a 3 couleurs maximum. Le jaune et le rouge attirent le plus l attention sur fond sombre. Le bleu et le vert fonctionnent bien sur fond clair. Evitez les palettes de couleurs trop nombreuses qui noient l oeil.
  • Texte - 2 a 5 mots maximum, police epaisse et lisible (Montserrat Bold, Impact, Bebas Neue). Le texte doit completer le titre, pas le repeter. Si le titre dit "Comment faire X", la miniature montre le resultat de X avec un mot comme "CA MARCHE".
